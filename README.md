# Miles Coviello

Computer science student at Northeastern University, and a ski racer from
Vermont. I work on Linux, homelab and systems projects.

Website: [milescoviello.com](https://milescoviello.com)

### Projects

| Project | What it is |
| --- | --- |
| [OS-DEV](https://github.com/milescoviello/OS-DEV) | A hobby x86-64 OS: kernel, TLS 1.3, a JavaScript engine and a sandboxed web browser, with DOOM and Quake ported as apps. |
| [mnemosyne](https://github.com/milescoviello/mnemosyne) | A terminal browser for your Claude Code history: search, tag and resume any past session, across every folder. |
| [steelmc](https://github.com/milescoviello/steelmc) | Configure SteelSeries gear on Linux with no vendor software: keyboards, mice, headsets and more, from an app or the command line. |
| [theia](https://github.com/milescoviello/theia) | A terminal browser for a homelab: every Proxmox node, VM and container, and the Docker containers inside them, in one live list. |
| [homelabdashboard](https://github.com/milescoviello/homelabdashboard) | Live homelab monitoring dashboard: K3s + FastAPI + SSE, with real-time CPU/RAM/temp for K3s nodes and Proxmox hosts. |
| [honeyshell](https://github.com/milescoviello/honeyshell) | A Debian 13 shell emulator faithful enough to put behind an SSH honeypot, with 237 differential test suites |
| [music](https://github.com/milescoviello/music) | Native SwiftUI music client for Navidrome (iOS and linux) |
| [nowplaying](https://github.com/milescoviello/nowplaying) | Live lyrics ticker for the KDE Plasma 6 panel, with homelab status when the music stops |
