Systems and tools developer. I like building things from the ground up — operating
systems, the Linux plumbing underneath them, and the automation that keeps a sprawling
home lab running.

- 🛠️ **Low-level systems** — a from-scratch x86-64 OS, Linux/Gentoo internals, kernel work
- 🏠 **Homelab & infra** — Proxmox / k3s / Docker fleet, Go + Python control planes, monitoring
- 📱 **Native apps** — SwiftUI clients for self-hosted media
- 🌐 [milescoviello.com](https://milescoviello.com)
