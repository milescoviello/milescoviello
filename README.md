# Miles Coviello

Computer science student at Northeastern University, and a ski racer from
Vermont. I work on Linux, homelab and systems projects.

Website: [milescoviello.com](https://milescoviello.com)

### Projects

| Project | What it is |
| --- | --- |
| [OS-DEV](https://github.com/milescoviello/OS-DEV) | A hobby x86-64 OS: kernel, TLS 1.3, a JavaScript engine and a sandboxed web browser, with DOOM and Quake ported as apps. |
| [mnemosyne](https://github.com/milescoviello/mnemosyne) | A terminal browser for Claude Code history: search, tag and resume any past session, across every folder. |
| [theia](https://github.com/milescoviello/theia) | A terminal browser for a homelab: every Proxmox node, VM and container, and the Docker containers inside them, in one live list. |
| [homelabdashboard](https://github.com/milescoviello/homelabdashboard) | Live homelab monitoring: k3s + FastAPI + SSE, CPU/RAM/temp across nodes and Proxmox hosts. |
| [honeyshell](https://github.com/milescoviello/honeyshell) | A Debian 13 shell emulator for an SSH honeypot, checked by differential tests. |
| [music](https://github.com/milescoviello/music) | Native SwiftUI music client for Navidrome on iOS. |
| [apex-oled](https://github.com/milescoviello/apex-oled) | Drive the OLED on a SteelSeries Apex Pro Gen 3 keyboard from Linux, with no vendor software. |
| [nowplaying](https://github.com/milescoviello/nowplaying) | Live synced-lyrics ticker for the KDE Plasma 6 panel. |
